PANDUAN eSPJ-Kontribusi — Versi Halaman Mandiri (index.html)
=============================================================
Aplikasi lengkap dalam SATU file: formulir "Data Pelatihan" ->
9 dokumen SPJ format F4 yang terisi otomatis, dapat disunting
bebas, dan disimpan permanen.

ISI PAKET
---------
1. index.html           -> aplikasi lengkap dalam satu file (buka langsung di browser)
2. setup-database.sql   -> struktur database + data awal (untuk penyimpanan bersama/berbagi)
3. PANDUAN.txt          -> file ini

DUA MODE PENYIMPANAN
--------------------
* Mode Lokal (bawaan)   : tanpa konfigurasi apa pun. Data tersimpan di
                          perangkat/browser yang dipakai. Cocok untuk
                          dicoba langsung atau penggunaan satu komputer.
* Mode Server (opsional): data tersimpan terpusat pada server data instansi,
                          dapat diakses dari komputer mana pun. Aktivasi
                          lewat tombol status di kanan atas aplikasi.

====================== A. PAKAI LANGSUNG (Mode Lokal) ======================
1. Klik dua kali index.html (buka di browser: Chrome/Edge/Firefox).
2. Selesai — 5 kegiatan contoh dari file Excel langsung tersedia.
   Jika belum: Dashboard -> tombol "Isi Data Awal".
3. Semua perubahan (formulir, suntingan dokumen, pejabat, pengaturan)
   otomatis tersimpan di perangkat tersebut.

====================== B. HOSTING HALAMAN (opsional) ======================
Agar dapat dibuka dari mana saja tanpa instalasi:
1. Siapkan akun pada layanan hosting halaman statis pilihan Anda.
2. Buat "repositori/situs" baru, beri nama mis. espj-kontribusi.
3. Unggah file index.html (cukup satu file ini; file .sql tidak wajib).
4. Aktifkan fitur "Pages"/publikasi situs pada pengaturan repositori
   (cabang utama, folder root).
5. Tunggu 1-3 menit, lalu buka alamat situs yang diberikan layanan.

====================== C. SERVER DATA TERPUSAT (opsional) ======================
Digunakan bila data harus sama & tersambung antar banyak komputer.

C.1 PASANG STRUKTUR DATABASE
1. Buat proyek pada layanan penyimpanan basis data pilihan Anda
   (yang menyediakan database PostgreSQL + SQL Editor).
2. Buka menu "SQL Editor" -> salin SELURUH isi setup-database.sql -> Run.
3. Tabel yang terbentuk: kegiatan, participant, pejabat, pengaturan,
   dokumen_sunting (penyimpanan hasil suntingan dokumen SPJ)
   + data contoh 5 kegiatan dari file Excel.

C.2 HUBUNGKAN APLIKASI (2 cara, pilih salah satu)
CARA 1 — lewat aplikasi (disarankan, tanpa edit file):
1. Buka aplikasi (lokal maupun alamat situs hasil langkah B).
2. Klik tombol status di KANAN ATAS (bertuliskan "Mode Lokal").
3. Isi Alamat Server Data & Kunci Akses Publik dari layanan Anda
   -> "Simpan & Uji".
4. Status berubah hijau "Tersambung — Server Data" dan data langsung muncul.
   (Konfigurasi tersimpan di browser; ulangi sekali saja per komputer.)

CARA 2 — lewat edit file:
1. Edit index.html (ikon pensil bila di hosting).
2. Cari baris:  const KONFIG_SERVER = {
3. Isi SERVER_URL dan KUNCI_AKSES di antara tanda kutip -> simpan.

========================== D. FITUR APLIKASI ==========================
- Dashboard          : statistik nilai kontribusi, peserta, PPh 23, kelengkapan BA
- Data Pelatihan     : formulir master 6 tab (pengganti sheet "Data Pelatihan")
  1. Kegiatan  2. Vendor  3. Invoice & Rekening  4. Berita Acara
  5. Nilai & Pajak (jumlah biaya & PPh23 & terbilang otomatis)
  6. Peserta Penggantian (baris sheet "Daftar Pembayaran Penggantian U")
- Dokumen SPJ (F4)   : 9 dokumen terisi otomatis dari formulir:
  Cover, BAP, BAST, BA Pembayaran, BA Bermaterai, Bukti Pengeluaran (Bend. 20),
  Lembar Disposisi, Daftar Pembayaran Penggantian Uang (F4 landscape),
  Surat Pernyataan PA/PPTK
- Pejabat & Pengaturan: kop surat, program/kegiatan, kode rekening, data pejabat

===== E. MENYUNTING DOKUMEN SECARA BEBAS (BARU) =====
Seluruh isi dokumen dapat diubah langsung, lalu disimpan permanen:
1. Menu "Dokumen SPJ (F4)" -> pilih kegiatan & dokumen.
2. Klik "Edit Dokumen" -> mode sunting aktif (bingkai kuning).
3. Klik langsung teks/angka pada dokumen, ketik untuk mengubah apa pun:
   nomor surat, kalimat, nilai, isi tabel, sampai nama pejabat.
4. Klik "Simpan Dokumen" -> perubahan tersimpan permanen
   (pada Mode Lokal: di perangkat; pada Mode Server: di tabel
   dokumen_sunting sehingga sama di semua komputer).
5. Dokumen yang pernah disunting diberi tanda "Tersunting".
   Mengubah data formulir TIDAK lagi mengubah dokumen tersebut.
6. Tekan "Reset" untuk membuang suntingan dan kembali ke isi otomatis.
7. Cetak kapan saja: "Cetak F4" selalu mencetak tampilan terakhir
   (termasuk suntingan yang belum disimpan sekalipun).

========================== F. MENCETAK F4 ==========================
1. Menu "Dokumen SPJ (F4)" -> pilih kegiatan & dokumen -> "Cetak F4"
2. Pada dialog printer:
   - Paper size : F4 / Folio / Legal (215 x 330 mm)
   - Margins    : Default / None
   - Scale      : 100 (jangan "Fit to page")
   - Matikan "Headers and footers"
3. Daftar Pembayaran otomatis landscape (330 x 215 mm)

Tips bila printer tidak punya ukuran F4: pilih Legal lalu atur
skala 100%; ukuran F4 sedikit lebih panjang dari Legal.

========================== G. KEAMANAN DATA ==========================
- Kunci akses publik memang sifatnya publik (dipakai dari browser);
  yang menjaga keamanan adalah Row Level Security (sudah diaktifkan).
- Konfigurasi bawaan membuka akses penuh agar aplikasi internal
  dapat langsung dipakai tanpa login. Untuk memperketat, aktifkan
  fitur autentikasi layanan Anda lalu sesuaikan policy pada
  setup-database.sql (lihat catatan bawah file).
- Jangan gunakan kunci akses tingkat admin di aplikasi!
- Unduh cadangan data secara berkala melalui menu ekspor/backup
  layanan penyimpanan data yang Anda pakai.

========================== H. TROUBLESHOOTING ==========================
Masalah                            Solusi
---------------------------------  ------------------------------------------
Status merah "Koneksi gagal"       Periksa Alamat Server & Kunci Akses;
                                   pastikan setup-database.sql sudah di-Run
Data tidak muncul                  Cek SQL Editor: SELECT * FROM kegiatan;
                                   pastikan tidak kosong (pakai Isi Data Awal)
"relation ... does not exist"      Struktur belum dipasang -> ulangi langkah C.1
Suntingan dokumen hilang           Pastikan sudah menekan "Simpan Dokumen";
                                   bila di komputer lain, gunakan Mode Server
Dokumen terpotong saat print       Set paper F4/Folio & scale 100%
Lupa konfigurasi di komputer lain  Ulangi langkah C.2 (tersimpan per browser)

========================== I. ALUR KERJA HARIAN ==========================
1. Tambah kegiatan baru  -> menu Data Pelatihan -> Tambah Kegiatan
2. Isi data selengkap mungkin (nomor BA boleh menyusul)
3. Buka Dokumen SPJ -> semua dokumen sudah terisi
4. Bila perlu penyesuaian -> Edit Dokumen -> ubah langsung -> Simpan Dokumen
5. Cetak F4 sesuai kebutuhan (dapat diulang kapan saja)
6. Ubah data kapan pun -> dokumen yang belum disunting otomatis mengikuti
