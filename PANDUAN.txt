================================================================
 eSPJ-KONTRIBUSI — DINAS KESEHATAN KAB. KUTAI KARTANEGARA
 Termasuk EDITOR DOKUMEN PROFESIONAL (ala pengolah kata)
================================================================

CARA MENJALANKAN
1) Pasang Node.js 20+ (atau Bun).
2) Buka terminal di folder ini, jalankan:
     npm install        (atau: bun install)
     npx prisma generate
     npm run dev        (atau: bun run dev)
3) Buka http://localhost:3000

FITUR UTAMA
- Data Pelatihan  : formulir sumber tunggal (6 tab, 40 kolom).
- Dokumen SPJ (F4): 9 dokumen otomatis (Cover, BAP, BAST, BA Bayar,
  BA Bermaterai, Bukti Bend.20, Disposisi, Daftar Pembayaran,
  Pernyataan PA). Tombol "Cetak F4" mencetak pada kertas F4/Folio.
- Editor Dokumen  : sunting bebas seluruh dokumen seperti Word:
  * Ribbon 7 tab (Berkas, Beranda, Sisipkan, Tata Letak, Referensi,
    Tinjau, Tampilan)
  * Format huruf/paragraf, daftar, gaya (Judul 1-4), kutipan
  * Tabel lengkap: sisip baris/kolom, gabung/pisah sel, lebar kolom,
    garis, warna sel, kepala tabel berulang
  * Gambar: unggah, ubah ukuran (rasio terjaga), rata & keterangan
  * Kop/kaki halaman, nomor halaman otomatis, halaman pertama berbeda
  * Ukuran kertas F4/A4/A5/Letter/Legal/Kustom, orientasi, margin
  * Penggaris + inden + tab stop, spasi baris & paragraf
  * Daftar isi otomatis + perbarui, panel navigasi judul
  * Cari & ganti, hitung kata, ejaan, pilih bahasa
  * Simpan otomatis ke database (debounce), indikator tersimpan
  * Riwayat versi + pulihkan (versi lama tak pernah dihapus)
  * Ekspor: DOCX (Word asli), PDF (via dialog cetak), HTML, TXT
  * Impor: DOCX, HTML, TXT
  * Zoom 50-200%, pratinjau cetak, layar penuh, pintasan keyboard
    (Ctrl+B/I/U/Z/Y/F/H/S/P/K, Tab di tabel pindah sel)

DATABASE
- SQLite siap pakai di db/custom.db (berisi 5 kegiatan contoh).
- Struktur: prisma/schema.prisma (Kegiatan, Participant, Pejabat,
  Pengaturan, SpjDoc, SpjDocVersion).
- Cadangkan cukup dengan menyalin file db/custom.db.

CATATAN CETAK
- Ukuran kertas diatur pada dialog cetak sistem: pilih F4/Folio
  215 x 330 mm (Daftar Pembayaran: 330 x 215 mm mendatar),
  skala 100%, margin: None/Default tanpa header-footer browser.
- Di Editor Dokumen, tombol "Cetak / PDF" sudah mengatur ukuran
  halaman otomatis sesuai pengaturan dokumen.
